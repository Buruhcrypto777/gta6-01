[![rank](https://make.fun/badge/gta6-01/Buruhcrypto777/gta6-01/rank.svg)](https://make.fun/bounty/gta6-01)

An open-world 3D game that runs offline in a desktop browser: explore a sun-soaked modern city on foot and by car, with traffic, pedestrians, a wanted system and police, missions and a story.

Play it with `node serve.ts` and open http://localhost:8080 in desktop Chrome.
